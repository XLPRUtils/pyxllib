# KQ5034 历史表格实现

本目录是 KQ5034 考勤迁移到单一 CodeYun 架构后留下的只读历史资料。

## 目录

- `runtime/`：旧 `KqCourse`、单课程 JSA 与考勤总表 JSA。
- `courses/`：退役时仍放在活动课程目录中的旧架构课程。
- `completed_courses/`：更早的已完结旧架构课程。
- `shared_runtime_snapshots/`：拆除耦合前的 `kq5034.common/db/tools/order_ops` 快照。
- `research/`：桌面自动化与页面探针研究。
- `docs/legacy_AGENTS.md`：迁移前的项目说明。

## 历史工作流

旧实现把业务拆在 Python、在线表格和远端脚本三处：

1. Python 从小鹅通采集数据并写入本地数据库。
2. Python 把考勤内容写入在线表格。
3. JSA 在表格内计算、维护状态并回写结果。
4. Python 再读取结果执行后续动作和通知。

这套模型的主要维护成本来自跨运行时状态、远端脚本同步、非结构化表格定位和双端故障排查。现行考勤已经把表格读写、计算与状态统一到 CodeYun。

## 查阅规则

- 只用于理解历史业务和提取可验证的设计思想。
- 不把旧类、脚本或字段直接复制回当前考勤。
- 需要复用某段算法时，先去除平台耦合并为当前业务补测试。
- `runtime/*.js` 已移除当时的授权值和资源身份；占位符不可直接运行。
